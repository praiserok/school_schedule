# Система автоматичної генерації шкільного розкладу

Django-застосунок для автоматичної побудови тижневого розкладу уроків з урахуванням усіх обмежень: вчителів, кабінетів, класів, груп і дзвінків.

## Встановлення та запуск

```bash
# 1. Клонувати репозиторій
git clone <repo-url>
cd school_schedule

# 2. Створити віртуальне середовище
python -m venv .venv
source .venv/bin/activate       # Linux/Mac
.venv\Scripts\activate          # Windows

# 3. Встановити залежності
pip install django ortools

# 4. Застосувати міграції
python manage.py migrate

# 5. (Опціонально) Заповнити тестовими даними
python manage.py seed --clear

# 6. Запустити сервер
python manage.py runserver
```

Відкрити у браузері: **http://127.0.0.1:8000/**

## Сутності та їх логіка

### Вчитель (`Teacher`)
- **Прізвище, Імʼя** — ідентифікатор
- **Доступні дні** — бітова маска Пн–Пт (`11111` = всі дні, `11110` = Пн–Чт). Генератор **не ставить** уроки у недоступні дні
- **Макс. уроків на день** — верхня межа завантаженості. Генератор і ручний редактор перевіряють це обмеження

### Предмет (`Subject`)
- **Назва, Скорочення** — скорочення відображається у розкладі
- **Колір** — HEX-колір для візуального виділення у сітці розкладу
- **Дозволити спільний кабінет** — якщо увімкнено, два класи можуть одночасно займати один кабінет (наприклад, фізкультура у спортзалі)
- **Макс. різниця паралелей** — при спільному кабінеті: наприклад, `2` означає що у спортзалі можуть бути одночасно 3-й і 4-й клас, але не 1-й і 8-й

### Кабінет (`Room`)
- **Назва** — номер або назва (спортзал, хімлаб)
- **Спеціалізація** — якщо вказано предмет, кабінет використовується **тільки** для нього (спортзал → фізкультура)
- **Місткість** — інформаційне поле
- **Макс. класів одночасно** — для спортзалу зазвичай `2`: дозволяє одночасно двом класам проводити урок в одному залі (різні вчителі, різні половини)

### Клас (`SchoolClass`)
- **Паралель + Літера** — наприклад, `5А`. Літера необов'язкова (можна просто `5`)
- **Основний кабінет** — для початкової школи (1–4 клас): більшість уроків проходить у цьому кабінеті. Генератор надає йому пріоритет при розподілі кабінетів

### Навантаження (`TeacherSubject`)
Ключова сутність — визначає **хто** викладає **який предмет** у **якому класі** і **скільки годин на тиждень**.

- **Вчитель + Предмет + Клас + Годин/тиж** — основні поля
- **Група** — якщо клас ділиться на групи (наприклад, англійська): `1` або `2`. Групові уроки одного предмету в одному класі генератор розміщує **в один і той самий слот** (дві групи паралельно, різні кабінети, різні вчителі). При розрахунку навантаження класу вони рахуються як **1 урок**, а не 2

**Приклад поділу на групи:**
```
Іваненко | Англійська | 5А | 2 год | гр.1
Петренко | Англійська | 5А | 2 год | гр.2
```
→ генератор поставить обидва уроки в однаковий слот. Клас 5А ділиться навпіл.

### Розклад дзвінків (`BellSchedule`)
Набір часових проміжків для кожного уроку:
```
1 урок: 08:00–08:45
2 урок: 08:55–09:40
...
```
Один розклад дзвінків можна прив'язати до кількох розкладів занять. Відображається у сітці розкладу поруч із номером уроку.

### Розклад занять (`Schedule`)
Контейнер для згенерованих уроків:
- **Назва** — довільна (напр. "2025–2026 основний")
- **Днів на тиждень** — 1–5 (пн–пт)
- **Уроків на день** — максимальна кількість слотів
- **Розклад дзвінків** — прив'язка для відображення часів
- **Активний** — позначка активного розкладу (використовується на дашборді і в списках)

## Покрокова інструкція

### Крок 1 — Внести вчителів
Меню **Вчителі → Додати**. Для кожного вчителя:
- Прізвище та Імʼя
- Позначити доступні дні (за замовчуванням всі пн–пт)
- Встановити ліміт уроків на день (реальний для вчителя, зазвичай 5–7)

### Крок 2 — Внести предмети
Меню **Предмети → Додати**. Обов'язково:
- Додати скорочення (відображається у тісній сітці)
- Вибрати колір (щоб розклад був наочним)
- Для фізкультури — увімкнути "Дозволити спільний кабінет" та встановити різницю паралелей

### Крок 3 — Внести кабінети
Меню **Кабінети → Додати**:
- Спортзал: вказати спеціалізацію "Фізкультура" і `Макс. класів одночасно = 2`
- Хімлаб, фізлаб: вказати відповідну спеціалізацію
- Класні кімнати: без спеціалізації

### Крок 4 — Внести класи
Меню **Класи → Додати**:
- Паралель (1–11) та літера (А, Б, В або порожньо)
- Для 1–4 класів: вказати основний кабінет

### Крок 5 — Внести навантаження
Меню **Вчителі** → кнопка таблиці біля потрібного вчителя → **Навантаження**.

На цій сторінці відразу видно загальну суму годин вчителя. Для кожного рядка:
- Предмет, Клас, Годин на тиждень
- Група (тільки для поділу класу)

> ⚠️ **Важливо:** стежте щоб сума годин вчителя не перевищувала `Макс.уроків/день × кількість доступних днів`. Наприклад, якщо 5 днів × 6 уроків = 30 год/тиж — це максимум.

### Крок 6 — Налаштувати розклад дзвінків (опціонально)
Меню **Дзвінки → Додати**. Введіть назву та часи кожного уроку. Кнопка "Додати урок" автоматично заповнює номер.

### Крок 7 — Створити розклад занять
Меню **Розклади → Новий розклад**:
- Назва, кількість днів (1–5), уроків на день
- Прив'язати розклад дзвінків
- Позначити як "Активний" якщо це основний

### Крок 8 — Згенерувати розклад
Відкрити розклад → кнопка **"Згенерувати розклад"**. Генерація займає від секунди до 2 хвилин залежно від складності. Після завершення відображається кількість уроків і час генерації.

## Генерація розкладу

Використовується **OR-Tools CP-SAT** — solver для задач задоволення обмежень (Constraint Programming).

### Що гарантує генератор

| Обмеження | Опис |
|-----------|------|
| Кількість годин | Кожне навантаження виконується рівно стільки годин, скільки задано |
| Без конфліктів класу | Клас не може мати два уроки в один слот (крім групових) |
| Без конфліктів вчителя | Вчитель не може вести два уроки одночасно |
| Доступність вчителя | Уроки ставляться тільки у доступні дні |
| Ліміт вчителя | Не більше `max_lessons_per_day` уроків на день |
| Рівномірне навантаження | Кількість уроків на день у класу відрізняється не більше ніж на 1 (рівномірний розподіл по тижню) |
| Без вікон | Уроки класу йдуть підряд починаючи з 1-го (без "вікон" між ними) |
| Групові уроки | Групи одного предмету/класу ставляться в один і той же час |

### Розподіл кабінетів (після генерації)

Кабінети призначаються у порядку пріоритету:
1. Спеціалізований кабінет для цього предмету
2. Основний кабінет класу (якщо є і предмет не потребує спец. кімнати)
3. Будь-який вільний загальний кабінет

При спільному кабінеті (спортзал): перший клас отримує зал, другий — шукає інший вільний. Допускається тільки якщо предмет дозволяє спільний кабінет і різниця паралелей в межах ліміту.

### Якщо розклад не знайдено

Можливі причини:
- Сума годин вчителя перевищує його можливості (`= годин/тиж > днів × макс/день`)
- Класу фізично неможливо скласти розклад без вікон з такою кількістю годин і вчителів
- Дуже жорсткі обмеження в сумі роблять задачу нерозв'язною

**Що робити:** перевірте загальну кількість годин кожного вчителя на дашборді, порівняйте з лімітом.

## Ручне редагування

Після генерації розклад можна коригувати вручну.

**Як увімкнути:** кнопка **"Редагувати"** у шапці сторінки розкладу.

**Як переміщати урок:**
1. Клікнути на урок — він виділяється жовтою рамкою
2. Клікнути на іншу комірку **того ж класу**:
   - Порожня → урок переміщується туди
   - Зайнята → уроки міняються місцями (swap)
3. При успіху — сторінка оновлюється

**Що перевіряється при кожному переміщенні:**
- Доступність вчителя у новий день
- Відсутність конфлікту вчителя (вже веде урок у цей час)
- Відсутність конфлікту класу
- Ліміт уроків вчителя на день
- Зайнятість кабінету
- Відсутність вікон у розкладі класу після переміщення

Якщо хоча б одна перевірка не пройшла — показується повідомлення з описом і урок **не переміщується**.

**Клавіша Escape** або повторний клік на виділений урок — скасувати виділення.

> ⚠️ Переміщення допускається тільки **в межах одного класу**. Міняти уроки між різними класами не можна.

## Перегляд розкладу

### Сітка за класами
Головна сторінка розкладу. Кожен клас — окрема таблиця (рядки = уроки, стовпці = дні). Кожен предмет виділений своїм кольором (лівий бордер + фон).

**Швидка навігація:** рядок з іменами класів під шапкою — клік прокручує до потрібного класу.

### Розклад вчителя
Дропдаун **"Розклад вчителя"** або клік на прізвище вчителя у комірці. Показує персональну сітку: у комірці — предмет, клас, кабінет. Дропдаун дозволяє переключатися між вчителями.

### Завантаженість кабінету
Меню **Кабінети** → кнопка-календар біля кабінету. Показує які уроки і коли проходять у цьому кабінеті. Для спортзалу може показувати два уроки в одному слоті.

## Дашборд

Головна сторінка (`/`) — зведений огляд:
- **Лічильники** — кількість вчителів, предметів, кабінетів, класів, записів навантаження, уроків
- **Активний розклад** — назва, статистика, посилання на перегляд
- **Таблиця вчителів** — робочі дні, предмети, загальна кількість годин. Кнопки: розклад, навантаження, редагування

## Особливі випадки

### Початкова школа (1–4 клас)
- Вказати **Основний кабінет** у налаштуваннях класу
- Генератор автоматично намагається ставити всі уроки у кабінет класу, крім тих що вимагають спеціального приміщення

### Поділ класу на групи (англійська та ін.)
- Додати **два** записи навантаження для одного класу і предмету: один з `Група = 1`, інший з `Група = 2` (різні вчителі)
- Годин на тиждень у обох груп має бути однаково
- Генератор автоматично поставить обидва уроки в один слот

### Фізкультура з одним спортзалом
- У кабінеті "Спортзал": встановити `Макс. класів одночасно = 2`
- У предметі "Фізкультура": увімкнути `Дозволити спільний кабінет`, встановити різницю паралелей (рекомендовано `2`)
- Генератор автоматично підбере пари класів близьких паралелей при нестачі слотів

### Вчитель доступний не кожен день
- У налаштуваннях вчителя зняти позначки з недоступних днів
- Генератор не поставить жодного уроку цього вчителя в заблоковані дні
